La [galería actual](../../docs/GALERIA_SOCIAL.md) contiene la matriz completa de 19 estados y cuatro contactos de revisión. Las capturas fijas acreditan el aspecto de cada estado; las acciones se apoyan en pruebas y recorrido. Los dos conjuntos se conservan sin atribuir la evidencia de un avance a otro.
